# **Опис завдання**
У цій лабораторній роботі проводиться завантаження, очищення (Data Cleaning) та розширена візуалізація багатовимірного датасету **Automobile** з репозиторію UCI Machine Learning.

**Основні етапи роботи:**
* **Очищення даних:** Завантаження даних за прямим посиланням, обробка пропущених значень (заповнення середнім значенням та видалення порожніх рядків).
* **Базові візуалізації:** Побудова лінійного графіка, діаграми розсіювання та гістограми розподілу за 5 заданими ціновими діапазонами.
* **Багатовимірні графіки:** Використання кольору та розміру точок для відображення 4 вимірів на одному графіку, а також використання фасетних сіток для порівняння категорій.
* **Аналітичні графіки:** Побудова теплокарти кореляцій для числових атрибутів, фасетованого графіка кількості (Countplot) та графіків щільності. 
Загалом побудовано 7 інформативних графіків за допомогою бібліотек matplotlib та seaborn.
