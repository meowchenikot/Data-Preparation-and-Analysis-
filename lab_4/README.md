# **Опис завдання**
У цій лабораторній роботі створено програму з інтерактивним графічним інтерфейсом (GUI). 
Програма моделює гармонійний сигнал, накладає на нього нормальний (гауссівський) шум та фільтрує його в реальному часі.

**Основний функціонал:**
* Інтерактивні слайдери для зміни амплітуди, частоти та фази гармоніки.
* Інтерактивні слайдери для генерування шуму (середнє значення та дисперсія). Зміна параметрів гармоніки не призводить до перегенерації масиву шуму.
* Слайдер частоти зрізу для IIR-фільтра низьких частот (фільтр Баттерворта, `scipy.signal.butter`). Для уникнення зсуву фази використовується функція `filtfilt`.
* Чекбокси для увімкнення/вимкнення відображення зашумленого сигналу та відфільтрованої лінії.
* Кнопка скидання (Reset) до початкових параметрів.
* Кнопка з вбудованою інструкцією користувача.

# **Інструкція із запуску**

## **Клонування репозиторію та підготовка**
Відкрийте термінал та перейдіть у теку проєкту. **Створіть та активуйте віртуальне середовище:**

**Для Linux / macOS:**
```
python3 -m venv venv
source venv/bin/activate
```

**Для Windows (Command Prompt / PowerShell):**
```
python -m venv venv
venv\Scripts\activate
```

## **Встановлення необхідних залежностей (після активації середовища):**
```
pip install -r requirements.txt
```

## **Запуск коду**
Відкрийте термінал у папці з лабораторною роботою та запустіть головний скрипт:

```
python main.py
```
