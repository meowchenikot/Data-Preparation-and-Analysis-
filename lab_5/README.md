# **Опис проєкту**
Цей проєкт є інтерактивним веб-додатком, створеним за допомогою фреймворку Streamlit. Він дозволяє зручно візуалізувати та аналізувати часові ряди індексів VCI, TCI та VHI для різних областей України на основі супутникових даних NOAA.

**Склад проєкту:**
* `main.py` — головний файл веб-додатку (інтерфейс, фільтрація, побудова графіків).
* `get_data.py` — скрипт для автоматичного парсингу та очищення історичних даних безпосередньо з серверів NOAA.
* `vhi_data.csv` — локальний набір даних, згенерований скриптом `get_data.py`.
* `.streamlit/config.toml` — кастомна тема оформлення (кольори, шрифти).

## **Вимоги до системи**
**Python: 3.10** або вище.

# **Інструкція із запуску**

## **Клонування репозиторію та підготовка**
Відкрийте термінал та перейдіть у теку проєкту. **Створіть та активуйте віртуальне середовище:**

**Для Linux / macOS:**
```
python3 -m venv venv
source venv/bin/activate
```

**Для Windows (Command Prompt / PowerShell):**
```
python -m venv venv
venv\Scripts\activate
```

## **Встановлення необхідних залежностей (після активації середовища):**
```
pip install -r requirements.txt
```

## **Завантаження даних (Обов'язково)**
Для роботи програми необхідно завантажити пак даних. Перед запуском основної програми, обов'язково запустіть парсер, який завантажить і підготує дані:
```
python get_data.py
```

## **Запуск веб-додатку**
Щоб відкрити дашборд у браузері, виконайте команду:
```
streamlit run main.py
```
