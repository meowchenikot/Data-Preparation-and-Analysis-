# **Опис завдання**
У цій лабораторній роботі cтворено C++ програму, яка в циклі:
Читає відео з камери.
Відображає його у вікні.
Реагує на натискання клавіатури та миші.
Вмикає різні режими обробки зображень в залежності від натиснутих клавіш.

# **Вимоги до системи**
* **ОС**: Debian 11/12 (або будь-який дистрибутив на базі Debian/Ubuntu).
* **Залізо**: Наявність веб-камери (пристрій `/dev/video0`), мінімум 2 ГБ оперативної пам'яті.
* **Програмне забезпечення**: Утиліта `sudo` для встановлення залежностей.

# **Інструкція із запуску**
Надайте права на виконання скрипту встановлення (якщо вони відсутні після клонування):
   ```
   chmod +x preinstall.sh
   ```

Запустіть скрипт встановлення залежностей (тут буде потрібне sudo, адже в скрипті використовуються команди по встановленню пакетів, які без прав суперкористувача не спрацюють):
   ```
   ./preinstall.sh
   ```

Скомпілюйте проєкт:
   ```
   ./build.sh
   ```

Запустіть програму:
   ```
   ./run.sh
   ```

# **Керування**
* **Клавіша 1**: Звичайний режим
* **Клавіша 2**: Інверсія кольорів
* **Клавіша 3**: Gaussian blur
* **Клавіша 4**: Canny фільтр (виділення контурів)
* **Клавіша 5**: Glitch ефект (зміщення каналів)
* **Миша (ЛКМ)**: Затисніть та тягніть для малювання прямокутника.
* **Миша (ЛКМ) в будь-якому місці за межами картинки з камери**: Очистити намальований прямокутник.
* **Слайдер у вікні**: Зміна яскравості зображення.
* **ESC**: Вихід з програми.
