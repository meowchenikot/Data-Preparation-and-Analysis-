## **Опис завдання**
У цій лабораторній роботі створено C++ програму, яка читає відео з камери, обробляє його за допомогою класичного CV (OpenCV) та сучасного ML (детекція облич на базі ResNet-10). 
Головна особливість програми — вирішення проблеми блокування інтерфейсу важкими обчисленнями нейромережі за допомогою багатопотоковості (`std::thread`, `std::mutex`, `std::condition_variable`).

## **Архітектура програми (Опис класів)**
Програма має модульну структуру:
* `CameraProvider` — інкапсулює роботу з `cv::VideoCapture` (V4L2), отримує кадри з веб-камери.
* `KeyProcessor` — обробляє події клавіатури, перемикає режими обробки (enum `ProcessMode`).
* `FrameProcessor` — ядро візуальних фільтрів. Застосовує інверсію, Blur, Canny, Glitch ефекти, малює прямокутники мишею та накладає рамки облич.
* `Display` — відповідає за `cv::imshow`, реєстрацію колбеків миші та роботу слайдера яскравості.
* `FaceDetector` — відповідає за асинхронну детекцію облич за допомогою `cv::dnn`. 
  * Працює в окремому фоновому потоці (`std::thread`).
  * Для синхронізації передачі кадрів та отримання координат облич використовується `std::mutex`, щоб уникнути стану гонки (data race) з основним UI потоком.
  * Для оптимізації очікування нових кадрів використовується `std::condition_variable`.
  * У класі реалізовано штучне навантаження (`std::this_thread::sleep_for(500ms)`) для демонстрації незалежності потоків.

# **Інструкція із запуску**
Надайте права на виконання скрипту встановлення (якщо вони відсутні після клонування):
   ```
   chmod +x preinstall.sh
   ```

Запустіть скрипт встановлення залежностей (тут буде потрібне sudo, адже в скрипті використовуються команди по встановленню пакетів, які без прав суперкористувача не спрацюють):
   ```
   ./preinstall.sh
   ```

Скомпілюйте проєкт:
   ```
   ./build.sh
   ```

Запустіть програму:
   ```
   ./run.sh
   ```
